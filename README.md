## 👋 Sobre mim

Sou **José Nathan**, desenvolvedor de software e analista de privacidade, graduando em Sistemas de Informação e apaixonado por transformar desafios reais em produtos digitais úteis, seguros e bem construídos.

- 🚀 Desenvolvimento de aplicações web completas, do banco de dados à interface.
- ☕ Back-end com **Java, Spring Boot, Node.js e APIs REST**.
- ⚛️ Front-end moderno com **React e JavaScript**.
- 🐳 Infraestrutura com **Docker, AWS e integração contínua**.
- 🔐 Interesse em qualidade de software, privacidade, segurança e experiência do usuário.
- 📍 Guarabira, Paraíba — Brasil.
